# Calculadora Python

Calculadora de linha de comando desenvolvida em Python.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Validação de números
- Tratamento de divisão por zero
- Histórico de cálculos
- Limpeza do histórico

## Como executar

Execute o arquivo `calculadora.py` utilizando Python.
